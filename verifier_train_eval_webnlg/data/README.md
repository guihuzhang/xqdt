# WebNLG verifier data

This directory contains synthetic data-text pairs and error labels for training
and evaluating the WebNLG verifiers. It includes 35,426 training examples,
1,667 validation examples, and 1,779 test examples.

The shared [synthetic-data audit](synthetic_audit/README.md) contains 180 manually
checked examples: 90 from WebNLG and 90 from E2E. It includes the final human
decisions and a script to reproduce the audit results.
