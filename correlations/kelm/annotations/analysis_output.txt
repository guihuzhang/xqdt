    [Sample-Level Binary Classification of All-Correct Judgment]
    Positive class = "all correct" (model predicted no errors); Negative class = "has errors".
    TP = model said all-correct AND gold has no errors   (correct abstention).
    FP = model said all-correct BUT gold has errors      (dangerous miss: silent failure).
    FN = model predicted errors BUT gold has no errors   (false alarm at sample level).
    TN = model predicted errors AND gold has errors      (correctly flagged as erroneous).
    Bin-P   = TP / (TP+FP): among samples where model said all-correct, fraction truly all-correct.
    Bin-R   = TP / (TP+FN): among gold all-correct samples, fraction model correctly identified.
    Bin-F1  = harmonic mean of Bin-P and Bin-R.
    Bin-Acc = (TP+TN) / N: fraction of all samples where the model's judgment was correct.
