# KELM Human Verification

This directory contains the KELM sample, cached model outputs, de-identified
human annotations, and scoring code used for the KELM results in XQDT. It
covers the fine-tuned Qwen3 results in main-text Table 8, Appendix Tables
21--24, annotation agreement, and the prompted baselines.

## Contents

- `selected_kelm_10per_size_diverse.json`: the 60-example KELM evaluation set.
- `kelm_llm_predictions/`: cached predictions for the four fine-tuned Qwen3
  verifiers used in the paper.
- `annotations/human_annotations_main_*.jsonl`: annotations used to construct
  the final 240 model-example judgments.
- `annotations/human_annotations_agreement_*.jsonl`: the independently
  annotated overlap used for agreement analysis.
- `prompted_llm_results/`: GPT-5.1 and Qwen3-32B prompted predictions, completed
  item-level reviews, and the frozen Qwen3-32B aggregate result.

Annotator names are replaced with release-local anonymous IDs. The judgments
and evidence fields are unchanged.

## Fine-Tuned Qwen3 Results

Run from the repository root:

```bash
python correlations/kelm/annotations/anno_analysis_fin.py
```

The bundled `correlations/kelm/annotations/analysis_output.txt` is the frozen
paper run generated by this script. The historical script iterates over
an unordered overlap set, so a fresh process can shift bootstrap-only values
by a few tenths of a point; the underlying judgments and non-bootstrap counts
are unchanged.

## Annotation Agreement

```bash
python correlations/kelm/annotations/iaa_calc.py
```

The script evaluates 90 shared prediction judgments and 60 shared examples.

| Item | Krippendorff's alpha |
| --- | ---: |
| Prediction verification | 0.573 |
| Missed-error supplementation | 0.646 |

It writes the full report to
`correlations/kelm/annotations/annotation_process_agreement.txt` and exports
the common subsets used in the calculation.

```bash
python correlations/kelm/compute_qwen3_32b_scores.py
```

| Model | P | R | F1 | F1 95% CI |
| --- | ---: | ---: | ---: | --- |
| Q3-32B-Prompt | 35.4 | 38.1 | 33.2 | [25.2, 42.9] |

`prompted_llm_results/Qwen3-32B-Prompt_predictions.jsonl` contains the 60
model outputs. The prediction review and missed-error files contain the final
item-level decisions. `prompted_llm_results/Qwen3-32B-Prompt_scores.json`
provides a machine-readable copy of the paper result and strict sensitivity
analysis.
